# 随手抽屉 · Stash

**中文** | [English](README.en.md)

> 使用 AI 时随手把「稍后再查 / 再问」的片段收起来放到「抽屉」，需要时直接从「抽屉」里拿出来就地追问 —— 全程**低打扰、不打断心流**。

> 工作包名 `dsh-stash`。

---

## 设计原则（最重要）

**低打扰、不打断心流。**

- **随手收**：选中即存，无弹窗、不跳页、不打断当前对话。
- **就地问**：追问在当前页面小窗口内完成，不开新页。
- 你只管专注眼前，念头先交给抽屉，稍后再抽出来处理。

这个名字「随手抽屉」就是这套心法的写照——**「随手」= 低打扰、顺手；「抽屉」= 收纳，稍后抽出一条/几条就地追问**，存与问两个动作都被覆盖。

---

## 两个核心使用场景

### 场景一 · 随手收藏（专注当下）

> 在当前的聊天页面下，可以通过选取一段文字或词组，添加到一个地方（**抽屉**）存储起来，专注于当前对话内容。后续再去做额外的对话或问答。

- **触发**：查阅信息、调用文件、读回复时，遇到**不认识的关键词**、**有灵感的内容**、或任何想稍后再查的片段。
- **动作**：选中一段文字或词组 → 收进「抽屉」。
- **效果**：低打扰、不打断心流，专注眼前；念头先放一边，之后再统一处理。

### 场景二 · 随手抽屉（就地追问）

> 在当前的聊天页面下，可以通过选取一段文字或词组，或者从抽屉中，或者选取一个或多个内容，叠加在当前页面小窗口进行临时追问，追问时可以选择，是否加入上下文。

- **追问来源（可单选 / 多选）**：
  1. 当前聊天页面选中的一段文字或词组；
  2. 抽屉中的**一条**内容；
  3. 抽屉中的**一条或多条**内容。
- **呈现**：叠加在当前页面上的**小窗口**内就地追问，不开新页、不打断心流。
- **关键选项**：追问时可选择「**是否加入上下文**」——加入则带当前对话背景，不加入则只围绕选中内容独立问答。

---

## 这是什么

- **一句话**：把「此刻不想做 / 需要搜索但想稍后再做」的临时念头收起来，专注当前对话；需要时在页面浮窗里「抽一题」就地追问。
- **解决的问题**：用 AI 时经常遇到某个关键词、某段内容触发新灵感，或不理解需要搜索，但此刻不想分心，也不想重新开新页面。
- **形态**：DSH 插件（hybrid：宿主 remote + 存储 + LLM；客户端浮窗 UI + 文本选区捕获）。
