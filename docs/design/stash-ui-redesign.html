为什么这样改

去饱和蓝，换鼠尾草饱和蓝（#3b6ef0）是所有后台系统的默认色，见得越多越廉价。低饱和绿（#a3b8a6）在暖石墨上安静且自带辨识度，「自然」不是修辞——它的色相就是植物系的。
实线边框 → 半透明 hairline现状满屏 1px #3a4254 实线，每个区块都是一个盒子，廉价感主要来自这里。0.5px 半透明线在深底上若隐若现，整个面板只剩一条分隔线，其余靠留白分区。
文字只用两档字重现状标题 600 太重，等于在喊。改 500 + 0.01em 字距，配合三级灰色，层级靠明度不靠粗细。emoji（🗂）全部换线性 SVG 图标。
比例：选择是例外，未选是常态标签默认透明底，选中才着色；主按钮 sage 实底全站只有一个；删除平时是灰字，hover 才泛玫瑰色。视觉焦点永远少于两个，这叫克制。
动效只做入场面板 180ms scale .97→1 + 淡入，原点在右下角（从入口按钮方向长出来）；标签 hover 120ms 换底色。没有弹跳、没有位移、没有循环动画——除了加载骨架屏。
为二期主题适配铺路所有颜色走 CSS 变量，将来做浅色主题只需换一组 token 值，组件代码零改动（MVP 仍硬编码深色，范围纪律不变）。
