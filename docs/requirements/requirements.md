# 需求规范

> 来源：`docs/vision/idea.md`。所有 FR/NFR 都应可追溯到原文场景。

---

## FR（功能需求）

### FR-1 文本选区收藏（存）
- FR-1.1 用户在聊天页面**选取一段文字或词组**后，能触发一个轻量入口（选区旁浮钮 / 快捷键）。
- FR-1.2 通过该入口，可将选区**存入灵感库**。
- FR-1.3 收藏动作**不打断**当前对话、不弹大窗、不跳页。
- FR-1.4 收藏的条目**持久化**，会话结束 / 页面刷新 / 重启后仍在。

### FR-2 灵感库管理
- FR-2.1 有一个可随时打开/关闭的浮层，展示灵感库条目列表。
- FR-2.2 支持**查看、删除**条目（MVP）。
- FR-2.3（可选）支持为条目追加备注 / 标签 / 来源会话标注。
- FR-2.4（可选）支持按时间 / 会话过滤排序。

### FR-3 临时追问（问）
- FR-3.1 在**当前页面**的小窗口（浮窗）内进行追问，不新开页面。
- FR-3.2 追问内容来源三选一/多选：
  1. 当前聊天页面选取的一段文字或词组；
  2. 灵感库中的**一条**内容；
  3. 灵感库中的**一条或多条**内容。
- FR-3.3 支持在选中内容之外**追加自定义问题文本**。
- FR-3.4 追问时可选择「**是否加入上下文**」。
- FR-3.5 追问结果在浮窗内**就地返回**（流式或一次性，MVP 先一次性亦可）。
- FR-3.6 追问与主对话**互不污染**：不加上下文时，追问不会写进主对话历史。

### FR-4 选区即入口（问 + 存统一）
- FR-4.1 选区浮出的入口同时提供「收藏」与「追问」两个动作（或合并为一次选择）。

## NFR（非功能需求）

- NFR-1 **低打扰**：收藏动作 ≤ 1 次点击（不含选区本身）；无模态弹窗。
- NFR-2 **持久可靠**：灵感库数据在重启后不丢失（宿主侧持久化存储）。
- NFR-3 **热重载安全**：插件资源注册走 `ctx.effect`，热重载 / 卸载后无僵尸残留（工具、路由、监听、client 表全清理）。
- NFR-4 **版本不硬编码**：peerDependencies 用范围声明（`@deepseek-ai/* >=0.0.1-rc <2`、`cordis >=4.0.0-rc <5`）。
- NFR-5 **可观测**：关键操作（收藏 / 追问 / 失败）有日志与错误反馈。
- NFR-6 **性能**：选区监听不拖慢聊天页；灵感库规模较小时（< 数百条）列表渲染流畅。

## 验收标准（MVP）

| # | 场景 | 验收 |
|---|---|---|
| AC-1 | 选中对话文字 → 收藏 | 浮钮出现，点击后条目进入灵感库，刷新页面后仍在 |
| AC-2 | 打开灵感库 | 浮层可列出 / 删除条目 |
| AC-3 | 选一条 + 不加上下文追问 | 浮窗返回答案，且不写进主对话 |
| AC-4 | 多选多条 + 加自定义问题 + 加入上下文 | 浮窗返回结合多条内容与上下文的答案 |
| AC-5 | 卸载插件 | 无残留工具 / 路由 / 监听 / UI |

> 完整验收依赖「上下文来源」与「追问深度」两个待决项的确认，见
> [`docs/issues/open-questions.md`](../issues/open-questions.md)。
